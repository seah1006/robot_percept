# GA1 변경 및 검증 기록

## 변경 파일

- `sim/g1_grasp_env.py`: 접촉을 켠 고정 골반 G1/Dex3 장면, 상태, 위치 IK, 손 시너지, 마찰/P-gate/oracle, RGB 렌더.
- `tests/test_g1_grasp_env.py`: 정착·결정성·마스크·중력·손·상부 접근·weld 자세 보존 자체 테스트.
- `notes/m2a/ga1_changes.md`: 이 기록. 기존 env/IK/teleop 및 에셋은 수정하지 않음. 커밋·설치 없음.

## 장면과 제어

- `build_g1_xml`을 재사용한 뒤 이 환경 내부에서만 XML을 변경했다. 로봇 freejoint는 없고 물체 freejoint 한 개만 있다. 물체는 공통 계약의 치수·질량을 사용한다. dowel의 충돌 원기둥만 body x축과 평행하게 회전시켜 물체 body 사원수는 yaw를 나타낸다.
- 충돌 비트 `(contype, conaffinity)`: 양손 `(1,6)`, 테이블 `(2,5)`, 물체 `(4,3)`. 가능한 조합은 손–물체, 손–테이블, 물체–테이블뿐이다. 손목 자체·나머지 로봇·시각 geom·바닥은 `(0,0)`이다. `obj_table_contact`는 테이블/바닥 ID를 검사하지만 현재 바닥은 GA1의 충돌 제한에 따라 시각 전용이므로 테이블 아래로 낙하하면 높이 기준에서 실패한다.
- 테이블 중심 XY `(0.38,-0.20) m`, 상판 z `0.83 m`, 상판 `0.23×0.28×0.05 m`. 좌우/깊이 무작위 표본과 물체 반경을 수용하면서 휴식 손을 테이블 바깥에 둔다. 원본 `front`·`side` 카메라, offsamples=0.
- 접촉: `implicitfast`, dt `0.002 s`, `elliptic`, `impratio=10`, `noslip_iterations=3`. R-GRASP의 원뿔·접선 임피던스·잔류 슬립 억제 권고를 적용했고, dt는 계산량과 안착 안정성을 고려해 2 ms로 정했다. `solref=(0.008,1)`로 dt의 4배 시간 상수, `solimp=(.95,.99,.001)`, `margin=gap=0`. 손·물체 `friction=(1.2,.005,.0001)`, 테이블 `(.8,.005,.0001)`; `condim=4`로 미끄럼/비틀림, dowel은 `6`으로 롤링 저항도 포함한다. 이는 실물 재질에서 식별한 값이 아니다. 원본 손 충돌 mesh/엄지 box 유지: proxy로 바꾸면 접촉 위치가 달라지므로 이번 기준선에서는 교체하지 않았다.
- 로봇에만 `qfrc_bias` 보상, 물체의 6개 DOF에 `qfrc_applied=0`. 손은 고정 개폐 시너지와 원본 effort 제한을 유지하면서 위치 게인 45, 감쇠 1.4, 관절 마찰 손실 .03으로 조정했다. 팔·손 명령에 속도 제한을 적용한다.
- API 변경 없음. 추가 `pregrasp_pose(obj_pos,obj_yaw,height)`의 `height`는 물체 중심 기준 월드 z 오프셋, 사원수는 wxyz. 오른손 로컬 +Y(닫힘 방향)는 아래로 향하며 손바닥 위치는 로컬 +X 반대 방향으로 5.2 cm 물러나 있다. IK는 기존 `ArmIK`를 재사용해 손바닥 사이트에 적용하고, FK 잔차가 5 mm/4°를 넘으면 이전 목표를 유지한다.
- P-gate는 같은 손 엄지 + 검지/중지의 실제 MuJoCo 물체 접촉과 물체 중심의 로컬 영역 `x∈[-.015,.12]`, `닫힘축∈[-.015,.10]`, `|z|≤.060` m를 모두 요구한다. 현재 상대 포즈를 저장한 후 weld를 켜고 closure < .3에서 해제한다. `phys`에는 weld 없음. `oracle`은 무조건 부착하는 디버그 근사로 성능 판정에서 제외한다.

## 자체 검증

- `wsl -d Ubuntu-24.04 -- bash /tmp/m2a_ga1_verify.sh`: 공동 CPU 락 아래 `python -m pytest -q -p no:cacheprovider tests/test_g1_grasp_env.py`; **7 passed, 4.35 s**, 외부 Dash 플러그인 deprecation 경고 1개.
- `wsl -d Ubuntu-24.04 -- bash /tmp/m2a_ga1_render.sh`: `front`와 `side` 두 카메라에서 `(240, 320, 3)` RGB `uint8` 렌더 확인.
- Board seed 0–7의 IK 탐색에서 상대 높이 .16/.07/.135 m 목표는 8/8, .035 m는 7/8 수락. 이는 IK 목표 수락 수치이지 물리적 집기 성공률이 아니다. Seed 0 실제 접근에서 바로 상부 목표로 가면 손이 테이블에 걸린다. 먼저 동일 높이/방향에서 `p[0]=.13`인 테이블 앞 경유점으로 가면 실제 손바닥 잔차 약 2.4 mm(2초); 해당 경유점과 상부 접근은 테스트로 검증했다.
- `wsl -d Ubuntu-24.04 -- bash /tmp/m2a_ga1_smoke.sh`: Board seed 0, `phys`, 앞 경유점→물체 위 .16/.07/.035 m→닫기→.100 m 상승 명령→2.0초 유지. **실패 (`slip`)**. 닫은 뒤 검지·중지가 접촉하고 엄지는 미접촉, 샘플 관통 깊이 약 0.37 mm. 보드 중심 시작 z 약 .84249 m, 상승 동작 종료 및 유지 종료 시 테이블 아래로 떨어졌다. 실제 손바닥은 낮은 목표에서 테이블 접촉으로 약 52 mm 목표 오차가 있었다. 2초 유지 성공 주장은 하지 않는다.

## 미해결

- 잡기 전 열린 엄지와 테이블 간섭, 손목 자세 및 시너지, 팔 자세 추종을 추가 조사할 여지가 있다. P-gate가 이 스모크에서 열렸다는 결과는 없다. 손 위치/방향의 경로 계획은 호출자 책임이며 초기 경유점을 GA2에 공유했다. 20회 관문은 GA2 소유다.
