# Control API for evaluation (C -> E)

`Controller(env.model, env.data, env=env, gt_assist=True)` defaults to legacy behavior. `gt_assist=False` disables grasp weld and true-pose motion feedback in `pick_object` and `place_object`. Pass estimated `T_world_obj` to `pick_object(T_world_obj, bounds, object_pose_fn=gt_pose_callback)`. Callback is required for GT lift scoring (`ok`, `lifted`) only. `place_object(target_xy, object_pose_fn)` requires the same controller after pick; off-mode uses stored estimated `T_ee_obj = inv(planned_grasp) @ estimated_T_world_obj` and estimated pick z0, no true-pose XY correction or height gate. Callback is still used after release for scoring (`err_mm`, `upright`). No-weld mode may physically fail. `return_home(object_pose_fn=gt_pose_callback)` should be invoked after place retreat and verifies home joint error, contacts, object displacement. Worker pick command accepts `gt_assist` (default true); place inherits picked controller flag.

Follow-up: off-mode ok uses gripper width plus bilateral contact at closure, not GT lift. lifted and gt_lift_ok are diagnostic scores; default on-mode retains the GT lift gate. Both /robot/pick and /robot/place accept optional JSON boolean gt_assist; place defaults to inheriting pick setting. Home failure after a successful release is recorded in last_home and home_warning without changing successful place command status.
