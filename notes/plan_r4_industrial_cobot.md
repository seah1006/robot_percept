# r4 계획서: 유일 산업용·협동로봇 추가와 기구학 데이터 시각화

작성 2026-11-09 (부모 1NIgF2z2BvfBSkOh). 근거 자료: notes/yuil_specs.md(카탈로그 치수·사양), notes/TEAM_R3.md(작업 규칙).

## 1. 목표
웹 화면에서 **산업용 다관절 로봇**과 **협동로봇**을 골라, 같은 패널로 기구학 데이터(DH, 변환 행렬, 자코비안, 특이점, 작업 영역)를 실시간으로 보고 비교할 수 있게 한다. 포트폴리오·면접에서 FK/IK를 직접 만든 도구로 설명하는 것이 목적이다.

## 2. 결정 사항
- 시뮬레이터: **MuJoCo 유지, Isaac Sim 미사용** (최소 RTX 4080·VRAM 16GB·RAM 32GB, WSL2 미지원, NVIDIA 전용 → 회사 RTX 2080 SUPER 8GB, 집 AMD RX 7600 모두 불가).
- 로봇: 유일로보틱스 2종, 가반하중 12kg로 맞춘 공정 비교.

| | YMX-1210 (산업용 다관절) | YBL-A612 (협동로봇) |
|-|-|-|
| 가반하중 | 12kg | 12kg |
| 최대 작업 반경 | 1420mm | 1324mm |
| 본체 무게 | 165kg | 33.5kg |
| 반복정밀도 | ±0.06mm | ±0.1mm |
| J6 최대속도 | 420°/s | 180°/s |
| 구조(치수표 해석) | 구형 손목 6R: a1=160, 설치면→J2=387.6, a2=595, a3=150, d4=648.5, d6=115 | UR형 6R: d1=164, a2=626, a3=600, 손목 오프셋 98·82·128 |
| 치수 검증 | 160+595+√(150²+648.5²)=1420.6 ≈ 1420 | 626+600+98=1324 = 공식 도달거리 |

- 모델 성격: 카탈로그 치수 기반 **근사 모델**. 관절 배치·링크 길이는 치수표, 외형은 단순 도형, 질량·관성·J1~J5 한계·속도는 추정(화면에 '추정' 표기). 화면 문구: "유일 카탈로그 치수 기반 근사 모델(공식 CAD 아님)".
- 계산 검증 기준 로봇: UR5e(Menagerie, 제조사 공개 DH). 테스트 전용, 메뉴 노출은 선택.
- 기존 Panda·G1 기능은 그대로 둔다.

## 4. 구조
- 모델 생성: `tools/yuil_mjcf.py`가 notes/yuil_specs.md 치수로 MJCF를 만든다 → `assets/yuil/ymx1210.xml`, `assets/yuil/ybl_a612.xml`.
- 기구학 모듈: `sim/arm_kinematics.py`(DH 표, Aᵢ·T0i, 자코비안, 조작성, 특이점 판정, 6R 해석해 + 수치 IK). IK는 sim/humanoid_ik.py의 가중 DLS 재사용.
- 실행: 기존 worker 방식처럼 별도 프로세스(`web/arm_worker.py`), 렌더 30fps, 행렬 데이터는 `/status/ws`(WebSocket)로 10~15Hz.
- API: `/arm/mode`, `/arm/select`, `/arm/joints`(FK), `/arm/target`(IK), `/arm/status`, `/arm/export`.
- 화면: `web/static/arm.js`·`arm.css`, 기존 index.html의 로봇 선택에 연결(three.js 재사용).

## 5. 단계

| C. 서버 | arm_worker, API, WebSocket 데이터 | 30초 창 ≥29.7fps, 데이터 10~15Hz, 잘못된 입력 400 |
| D. 화면 | 패널 전체, FK/IK 조작, 비교·내보내기 | 브라우저 확인(스크린샷), 조작 지연 체감 없음 |
| E. 검증·문서 | 독립 검증, README 사용법, 한계 문서 | 아래 합격 기준 전부, 기존 Panda·G1 회귀 없음 |

## 6. 합격 기준 (검증자가 직접 재현한 원자료로만 PASS)
- 근사 모델 최대 작업 반경: YMX-1210 1420mm ±0.5%, YBL-A612 1324mm ±0.5%.
- DH FK vs MuJoCo 손끝 위치 ≤1µm, 방향 ≤1e-6 rad (YMX·YBL·UR5e, 무작위 1000자세).
- 자코비안 vs 수치미분 상대오차 ≤1e-6.
- IK: 작업 영역 내 무작위 목표 200개 성공률 ≥98%, p95 ≤33ms.
- 특이점 경고: 알려진 특이 자세(손목 θ5=0 등) 100% 경고, 일반 자세 오경고 ≤1%.
- 렌더 30초 창 ≥29.7fps, 전체 pytest 통과, 기존 Panda·G1 회귀 없음.
