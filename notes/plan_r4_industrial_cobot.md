# r4 계획: 유일 산업용 6축 + 유일 협동로봇 6축 추가와 기구학 데이터 시각화 (2026-11-09 사용자 결정, 카탈로그 반영본)

## 결정 사항
- Isaac Sim은 쓰지 않는다. 근거: 최소 사양 RTX 4080·VRAM 16GB·RAM 32GB, WSL2 미지원, NVIDIA RTX만 지원(회사 RTX 2080 SUPER 8GB, 집 AMD RX 7600 → 둘 다 불가). 현재 MuJoCo 구조를 확장한다.
- 로봇 선택 메뉴에 두 대를 추가하고 같은 기구학 패널로 비교한다. 기존 Panda·G1은 그대로.
- 사양·치수 출처와 기호 해석: notes/yuil_specs.md (카탈로그 PDF는 저장소에 넣지 않음).

## 로봇 (가반하중 12kg로 맞춘 공정 비교)
| | 유일 YMX-1210 (산업용 다관절) | 유일 YBL-A612 (협동로봇) |
|-|-|-|
| 가반하중 | 12kg | 12kg |
| 최대 작업 반경 | 1420mm | 1324mm |
| 본체 | 165kg | 33.5kg |
| 반복정밀도 | ±0.06mm | ±0.1mm |
| J6 최대속도 | 420°/s | 180°/s |
| 구조(추정) | KUKA/FANUC형 6R, 구형 손목: a1=A=160, d1≈B=387.6(설치면→J2), a2=C=595, a3=D=150, d4=E=648.5, d6=F=115 | UR형 6R: d1=A=164, a2=B=626, a3=C=600, d4·d5·d6·측면 오프셋은 D=98·E=82·F=128에서 결정 |
| 검증 근거 | A+C+√(D²+E²)=1420.6 ≈ H 1420 | B+C+D=1324 = G(A606에서 922.5로 동일 관계 확인) |
- 카탈로그 치수로 만든 **근사 모델**: 관절 배치·링크 길이는 치수표 기반, 외형은 단순 도형(상표·디자인 회피), 질량·관성·J1~J5 한계·속도는 추정. 화면에 "유일 카탈로그 치수 기반 근사 모델(공식 CAD 아님)" 표기.
- 치수 기호 해석(특히 YBL의 D·E·F, YMX의 B와 J1 원점)은 구현 초기에 그림과 작업영역 치수(I~M / H~L)로 교차 확인하고, 맞지 않으면 대안 해석을 notes에 기록.
- DH 계산 검증 기준용으로 UR5e(Menagerie, 제조사 공개 DH)를 테스트 전용으로 사용(메뉴 노출은 선택).
- 다른 체급 옵션: YMX-2510(25kg) / YBL-A620(20kg), 소형은 YBL-A606(6kg, 922.5mm).

## 구조
- 기존 sim_worker/humanoid_worker 방식처럼 별도 워커 프로세스, 렌더 30fps, 행렬 데이터는 /status/ws(WebSocket) 10~15Hz.
- IK는 sim/humanoid_ik.py의 가중 DLS 재사용(6R 구형 손목은 해석해와 비교 가능).
- UI는 기존 index.html + three.js 위에 패널 추가. MJCF는 assets/yuil/(신규) 아래 파라메트릭 생성 스크립트(tools/yuil_mjcf.py)로 만들고 치수는 notes/yuil_specs.md 값을 사용.

## 합격 기준 (구현 Codex / 검증 Claude 페어)
- 근사 모델의 최대 작업 반경: YMX-1210 1420mm ±0.5%, YBL-A612 1324mm ±0.5%; 작업영역 외곽 치수(YMX I~M, YBL H~L) 해석이 맞는 항목은 ±2%.
- DH FK vs MuJoCo 손끝 위치 ≤1µm, 방향 ≤1e-6 rad (YMX·YBL·UR5e, 무작위 1000자세).
- 자코비안 vs 수치미분 상대오차 ≤1e-6.
- IK: 작업 영역 내 무작위 목표 200개 성공률 ≥98%, p95 ≤33ms.
- 특이점 경고: 알려진 특이 자세(손목 θ5=0 등)에서 100% 경고, 일반 자세 오경고 ≤1%.
- 렌더 30초 창 ≥29.7fps, 기존 Panda·G1 회귀 없음, pytest 전체 통과.
