# Ground-truth use audit in control

- `web/sim_worker.py` pick: command estimated `T_cam_obj` is transformed by known camera extrinsics to world. `env.T_world_obj(name)` callback is passed into Controller for lift scoring and (legacy assist only) pre-pick z0.
- `sim/control.py:pick_object`: `object_pose_fn()` provides baseline z0 and post-lift displacement for `ok`/`lifted`. With `gt_assist=False`, z0 comes from the estimated input pose; post-lift reading is **scoring only**. Bilateral contact identifies the true body using MuJoCo contacts; `attach` uses true hand/object transforms to set a weld. Off disables weld entirely.
- `sim/control.py:place_object`: default `object_pose_fn` supplies true current object pose to derive `T_ee_obj`, orientation, and place height, corrects XY slip twice, and aborts release if true object height is too high. Off uses `inv(planned_grasp) @ estimated_object_pose`, carries it with the end effector, uses estimated pre-pick z0, and disables corrections/GT height abort. End-of-place `err_mm`/`upright` still read GT for **scoring only**.
- `sim/control.py:place`: the generic primitive optionally uses true `object_pose_fn` for relative offset and XY correction. Not used by worker's `place_object` route; callers must omit it to avoid GT feedback in an off-mode experiment.
- `sim/grasp.py:_neighbor_checker`: MuJoCo body positions associate estimated pose to nearest known object and true contact geometry rejects collisions with neighbors. This is simulation environment collision geometry and GT association, not image-derived recognition. Off does not remove this oracle association. IK itself evaluates exact robot simulation kinematics and contact geometry.
- `sim/control.py:return_home`: reads true object pose before/after for displacement **safety verification**, and uses simulation contacts to veto unsafe arm paths. It does not use object pose to generate motion.
- `web/sim_worker.py:publish`: emits true object transforms and center positions in `/status`; these are metadata and not used in the estimated-pose pick command, but clients must not treat them as inferred pose. Name selection upstream may use GT segmentation for oracle association.

Defaults preserve legacy assist behavior; `Controller(..., gt_assist=False)` and worker pick `gt_assist:false` are the comparison switch. Off is not a deployable perception-only robot stack because object identity, simulator contact detection, known camera extrinsics, and evaluation scoring still use simulation information.

Follow-up: off-mode ok no longer gates on GT lift; it requires gripper width and bilateral MuJoCo contact at grasp closure. lifted and gt_lift_ok remain scoring diagnostics. This still uses simulator contact identity, not deployable tactile sensing. The worker honors an optional gt_assist boolean in pick and place commands; web routes forward it.
